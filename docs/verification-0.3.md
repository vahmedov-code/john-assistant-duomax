  Также проверены SHA-256 настоящего архива, распаковка, целостность файлов,

  Только `ExpiredTargetSdkVersion` отключён намеренно: приложение устанавливается через ADB
  на YaOS с прежним targetSdk, а не публикуется в Google Play.
- Отдельный эмулятор JohnTest: Android 14/API 34, x86_64, 1280×800, 2 ГБ RAM.
  Установка обновлением `install -r` — Success, запуск MainActivity — Status ok.
- `VoiceSmokeInstrumentation` — PASS. Проверены настоящий native Vosk с русской моделью,
  создание распознавателя с ограниченной грамматикой, запуск AudioRecord,
  продолжение службы после сворачивания Activity, остановка, повторный запуск и освобождение
  ресурсов. BootReceiver вызван тестом: микрофон не запущен, состояние для ручного восстановления сохранено.
- В журнале Vosk модель и грамматика загружены, словарных ошибок в проверенной выборке не найдено.
- Интерфейс визуально проверен на экране эмулятора: видны статусы, скачивание/повторное скачивание,
  запуск и остановка; старые кнопки находятся ниже в прокручиваемом экране.
- Endpoint модели вернул HTTP 200 без редиректа. Официальный ZIP скачан по HTTPS,
  размер 46 236 750 байт, распакованный размер 91 289 240 байт. SHA-256 закреплён в коде.

Тест эмулятора использовал синтетический аудиовход без физической записи. Он подтверждает
работу native-библиотеки, загрузку модели и жизненный цикл микрофона/службы, но не точность
распознавания живой речи на станции. Передача модели в эмулятор выполнена отдельно для теста;
приложение скачивает её по своей кнопке. Полный сетевой цикл загрузчика на реальной YaOS
пока не проверен. Реальная станция не подключалась, установленное приложение не удалялось.

## Проверить на Duo Max

1. Установить APK из той же локальной сборки с прежним ключом: `adb install -r`.
   Не выполнять uninstall при несовместимости подписи.
2. Скачать модель кнопкой, проверить прогресс, отмену, повторную загрузку при обрыве и
   сохранение модели после закрытия приложения. Убедиться, что после установки модели
   команды работают при отсутствии интернета.
3. Разрешить микрофон, запустить Джона. Проверить все пять команд, варианты фраз, обращение
   в одной фразе и отдельное обращение. Команды без «Джон» и промежуточные результаты не исполняются.
4. Проверить распознавание рядом с работающей Алисой/Яндекс Музыкой, предупреждения о заглушённом
   входе, аппаратный mute, ложные срабатывания от музыки/телевизора и отсутствие повторов команды.
5. Выключить/заблокировать экран штатным способом. Проверить сохранение уведомления, реакции
   на команды, задержку и остановку. Затем оставить слушать длительно и измерить CPU/RAM.
6. Остановить из приложения и уведомления; убедиться, что микрофон освобождается и работает
   старая проверка микрофона. Перезапустить несколько раз.
7. Перезагрузить станцию: служба микрофона не должна самопроизвольно стартовать.
   Проверить сохранение модели и доступности ручного запуска; уведомление-напоминание зависит
   от разрешений уведомлений YaOS. После завершения процесса системой нужен ручной запуск.
8. Повторить старые рабочие сценарии громкости и MediaSession. Успешная отправка команды
   не равна подтверждению её исполнения самой Яндекс Музыкой.

## Изменённые компоненты

- app/build.gradle — версия, Vosk/JNA, unit-тесты и runner smoke-теста.
- AndroidManifest.xml — интернет для модели, foreground microphone, уведомления, wake lock, VoiceService.
- MainActivity.java — кнопки модели/запуска/остановки и отдельный статус Vosk; прежние ручные действия сохранены.
- BootReceiver.java — проверка action и напоминание о ручном возобновлении без старта микрофона.
- VoiceCommands.java, VoiceState.java, VoiceService.java — обработка обращения, состояние и foreground распознавание.
- MusicActions.java — вызов прежних Android API из службы, только для `ru.yandex.music`.
- ModelStore.java, ModelArchive.java — загрузка, SHA-256, ограниченная распаковка и проверка модели.
- app/src/test и app/src/androidTest — тесты парсера/архива и Android smoke-тест.
- README, THIRD_PARTY_NOTICES, assets/licenses и этот отчёт — инструкции и сведения о компонентах.

Ключи, пароли, SDK-пути, скачанный архив модели и APK не входят в Git.
